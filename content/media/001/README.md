## To publish them

1. Copy the files here with semantic names (`portada.jpg`, `sala.jpg`, …).
2. In `content/relatos/001-no-parti-el-dia-previsto.md`, add `cover:` and a
   `media:` list with `anchor:` values, and place the matching `[[anclaje]]`
   markers in the body where each image should fall.
3. Push. An anchor with no image behind it prints nothing, so the story stays
   correct at every intermediate step.

While there are no photographs, the story runs as a text-led piece: its
margin note is promoted into the column as a pull quote so the page is not one
unbroken wall.
